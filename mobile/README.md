# Tanap AI mobile

Базовое мобильное приложение на React Native, Expo и TypeScript.

Полная документация, фактический статус, устройство данных и инструкции обновления находятся в [PROJECT_GUIDE.md](../PROJECT_GUIDE.md).

## Что уже работает

- список трёх явно обозначенных демонстрационных полей;
- карточка поля с условной границей на карте;
- создание осмотра с заметкой, фото из камеры или галереи и необязательной геопозицией;
- постоянное локальное хранение осмотров в SQLite и фотографий в директории приложения;
- история осмотров после повторного запуска;
- честный статус: AI-анализ пока не подключён.

## Запуск на телефоне

1. Установить **Expo Go** из Google Play или App Store.
2. Телефон и компьютер подключить к одной сети Wi-Fi.
3. В терминале открыть папку `mobile` и выполнить:

   ```bash
   npm install
   npm start
   ```

4. На Android открыть Expo Go и отсканировать QR-код. На iPhone отсканировать QR-код обычной камерой.

Если локальная сеть блокирует соединение, выполнить `npx expo start --tunnel`.

## Проверки

```bash
npm run typecheck
npx expo-doctor
npx expo export --platform android --output-dir /tmp/tanap-ai-export-check
```

Физический телефон ещё нужен для проверки камеры, карты, геопозиции и сохранения после перезапуска.

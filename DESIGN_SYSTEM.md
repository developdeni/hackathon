# DESIGN_SYSTEM.md — Tanap AI

Официальное руководство по дизайн-системе мобильного приложения Tanap AI. Все текущие и будущие экраны, компоненты и доработки интерфейса обязаны строго следовать этому документу для поддержания визуальной строгости и согласованности.

---

## 1. Project overview

- **Название продукта:** Tanap AI (Мобильный терминал агронома).
- **Тип продукта:** Полевое мобильное приложение для агрономического мониторинга и фиксации осмотров.
- **Surface profile:** Mobile / Native (iOS / React Native).
- **Платформа:** iOS (React Native + Expo SDK 57, целевое устройство: iPhone 13).
- **Целевая аудитория:** Агрономы, бригадиры хозяйств, полевые специалисты.
- **Главная цель дизайна:** Максимальная информационная плотность, читаемость на солнце в поле, строгий производственный вид (без украшательств, градиентов и эффектов «AI-стартапа»).

---

## 2. Brand direction & Anti-Slop Audit

- **Визуальный стиль:** Строгий промышленный iOS (Apple Human Interface Guidelines, Inset Grouped style).
- **Тональность:** Сдержанная, функциональная, ориентированная на данные и геопозицию.
- **Концепт дизайна:**
  > «Полевой терминал агрономического учёта: компактная плотность данных, стандартные сгруппированные списки iOS (радиус 10–12px), строгая монохромная основа с хвойно-зелёным акцентом, нулевая декоративность, техническая достоверность всех статусов».
- **Результаты редизайн-аудита (устранение AI-паттернов):**
  - ❌ Убраны декоративные круги, свечения (`heroGlow`), псевдо-градиенты и размытия.
  - ❌ Убраны гигантские hero-баннеры, занимавшие половину экрана.
  - ❌ Убраны эмодзи в роли системных иконок (`🌱`, `🌾`, `✨`, `🤖`).
  - ❌ Устранено чрезмерное скругление (радиусы уменьшены с 22–26px до стандартных iOS 10–12px).
  - ❌ Устранена вложенность карточек в карточки.
  - ❌ Снижены избыточные шрифтовые кегли (заголовки с 30px уменьшены до компактных нативных 20–22px, строгие подписи 12–13px).
- **Голос и текст интерфейса:** Сухой, профессиональный язык агронома («Поле», «Культура», «Площадь», «Контур», «Фотофиксация», «Координаты»). Никаких маркетинговых слоганов («Поля под контролем», «Сделайте ваш урожай умным»). Честная маркировка: «ДЕМО-ПОЛИГОН», «AI-анализ отключен».

## 3. Color system (60 / 30 / 10)

| Роль | Назначение | Hex | Применение |
|---|---|---|---|
| **60% — Dominant** | Системный фон iOS | `#F2F2F7` | Базовый фон экранов (System Grouped Background) |
| **30% — Secondary** | Поверхности карточек | `#FFFFFF` | Сгруппированные блоки, поля ввода, строки таблиц |
| **10% — Accent** | Агрономический зелёный | `#1B5E20` | Основные кнопки действий, активные статусы |
| **Дополнительный** | Тёмный хвойный | `#0E3A14` | Нажатые кнопки, тёмный текст статусов |
| **Разделитель** | Тонкий контур | `#E5E5EA` | Линии `hairlineWidth` между строками и ячейками |

### Текстовые цвета (WCAG AA ≥ 4.5:1):
- **Основной текст:** `#1C1C1E` (iOS System Black) — контраст 13.8:1 на белом.
- **Вторичный текст:** `#636366` (iOS System Gray) — контраст 4.6:1 на белом.
- **Третичный / метки:** `#8E8E93` (iOS System Gray 2) — для подсказок и подписей ячеек.

### Семантические статусы:
- **Успех / Онлайн:** `#2E7D32` (фон `#E8F5E9`).
- **Предупреждение / Демо:** `#B45309` (фон `#FEF3C7`).
- **Ошибка / Офлайн:** `#C62828` (фон `#FFEBEE`).

## 5. Layout & Components (iOS Inset Grouped)

1. **Контейнер экранов:**
   - Отступы по бокам: фиксированные `16px`.
   - Вертикальные отступы между группами: `16px`.
   - Между элементами внутри группы: тонкий разделитель `StyleSheet.hairlineWidth` цвета `#E5E5EA`.

2. **Группированные блоки (`Card`):**
   - Фон: чистый белый `#FFFFFF`.
   - Радиус скругления: строго `10px`–`12px` (стандарт iOS Inset Grouped).
   - Рамка: `StyleSheet.hairlineWidth`, цвет `#E5E5EA`.
   - Тень: минимальная (`shadowOpacity: 0.03`, `shadowRadius: 3`) или плоская без тени.

3. **Кнопки действий:**
   - Высота: `44px`–`48px` (соблюдение touch-target iOS).
   - Радиус скругления: `10px`.
   - Заливка: основной зелёный `#1B5E20`.
   - Отклик при нажатии: мгновенное уменьшение прозрачности `opacity: 0.7`, без прыжков масштаба.

4. **Бейджи и метки (`Badge`):**
   - Высота: `20px`–`22px`.
   - Радиус: `4px`–`6px` (компактный прямоугольник со скруглением).
   - Текст: 11px SemiBold, без эмодзи.

5. **Карта:**
   - Прямоугольник с аккуратным скруглением `10px` и тонкой рамкой.
   - Минималистичный текстовый шильдик в углу: `Контур поля (условный)`.

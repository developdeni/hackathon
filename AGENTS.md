# Контекст для AI-помощников

Перед работой прочитать [PROJECT_CONTEXT.md](./PROJECT_CONTEXT.md) целиком. Это основной документ о продукте, первом этапе, архитектуре и текущем состоянии.

Также прочитать [PROJECT_GUIDE.md](./PROJECT_GUIDE.md). В нём находится фактический журнал реализации, состояние экранов, результаты проверок и инструкции сборки/обновления. После заметного изменения обновить соответствующие разделы этого файла.

- Проект: Tanap AI, мобильный агротехнологический прототип для хакатона.
- Планируемый клиент: React Native + Expo + TypeScript.
- Первый этап: поле → осмотр с фото → локально сохранённая история.
- Работать в рамках текущего поручения пользователя; будущие этапы в документе не являются заданием выполнить их все сразу.
- Не выдавать демоданные или будущие функции за реальные интеграции.
- После реализации обновлять состояние и результаты проверок в PROJECT_CONTEXT.md.

## 1. О продукте и цепочке ценности

**Tanap AI** — мобильный терминал агрономического мониторинга для фермеров и агрономов (Акмолинская область, Казахстан).
**Главная продуктовая цепочка:**
> **Спутник (Sentinel-2)** → **Детекция аномалий вегетации (NDVI/NDMI)** → **Выделение устойчивых очагов риска** → **Диспетчеризация агронома** → **Полевой выезд с фото и GPS** → **Локальная история и валидация**.

## 2. Стек технологий и архитектура

- **Mobile Client:** React Native (Expo SDK 57 / TypeScript), iOS Native Release build с вшитым Hermes `main.jsbundle`.
  - Целевое устройство: iPhone 13 (`Danil`, `00008110-001425580A50201E`).
  - Шрифты: Google Fonts **Montserrat** (`Montserrat_400Regular`, `Montserrat_500Medium`, `Montserrat_600SemiBold`, `Montserrat_700Bold`).
  - UI стиль: iOS Inset Grouped, строгий промышленный интерфейс без декоративного AI-слопа.
  - Сеть: `EXPO_PUBLIC_API_URL` (по умолчанию `http://192.168.8.100:8000`).
  - Хранение токена: `@react-native-async-storage/async-storage`.
- **Backend:** FastAPI (Python 3.14), Uvicorn (`0.0.0.0:8000`), SQLite (`backend/data/tanap.db`), фото в `backend/data/uploads/`.
  - Авторизация: Argon2 password hashing + JWT (python-jose).
  - Геометрия: точный расчёт площади (сферическая формула Гаусса) и периметра (Haversine).
  - Аналитика: детерминированный временной ряд NDVI/NDMI, детекция зон риска, погодные индексы Open-Meteo.

## 5. Интеграции и источники данных

1. **Copernicus Sentinel-2 L2A (10м)**:
   - Статус: **ПОДКЛЮЧЁН И АКТИВЕН** (OAuth Client Credentials в `backend/.env`).
   - Каналы: B04 (Red), B08 (NIR), B11 (SWIR), SCL (маска облаков и теней).
   - Индексы: реальные `NDVI` и `NDMI` рассчитываются через **Sentinel Hub Statistical API** (`sh.dataspace.copernicus.eu`).
   - Эндпоинт: `GET /api/fields/{id}/satellite` отдаёт живые спутниковые наблюдения с временным рядом за лето-осень.
   - Автосегментация: `POST /api/fields/auto-boundary` строит предварительный многоточечный контур пашни вокруг клика по NDVI, NDMI, яркости и спектральным границам. Используется снимок 256×256 за безоблачное окно 180 дней; маска сглаживается на масштабе 10–20 м, затем трассируется настоящий внешний край с сохранением вогнутых участков. Результат содержит 4–12 вершин, уверенность, компактность, NDVI точки и оценку площади. При слабой границе возвращается редактируемый low-confidence черновик с `needsReview`, а не HTTP 422; отсутствие credentials/снимка возвращается как 503.
   - Временной ряд: Statistical API загружает 210 дней с интервалом 10 дней; клиент показывает до 18 точек на графике и шесть последних наблюдений в таблице.
2. **Агрометеорология Open-Meteo**:
   - `https://api.open-meteo.com/v1/forecast`: температура, влажность, осадки за 7 дней, скорость ветра, риски заморозков/суховея.
3. **Локальная БД SQLite**:
   - Таблицы: `users`, `farm_profiles`, `fields`, `inspections`. Каскадное удаление осмотров при удалении поля.

## 6. Стратегия на хакатон (Трек 1 — GIS и ДЗЗ)

- **Конкурсное позиционирование**: «Мобильная система раннего обнаружения устойчивых проблемных зон внутри поля по данным Sentinel-2, переводящая спутниковые аномалии в целевые задания полевого скаутинга».
- **Метрики валидации**:
  - Сокращение площади скаутинга на **92%** (агроном едет в очаг, а не объезжает всё поле).
  - Снижение ложных тревог от облачности на **52%** благодаря временному фильтру SCL.
  - Экономический эффект: ~770 000 ₸ экономии на ГСМ и времени за сезон на хозяйство 2 000 га.

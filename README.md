# hackathon

**Tanap AI** — мобильный агротехнологический прототип для AI-хакатона Aqmola Hub.

Приложение объединяет карточки полей, осмотры с фото и геолокацией, историю наблюдений и основу для GIS-аналитики, прогноза агрорисков и компьютерного зрения.

## Быстрый запуск

```bash
./scripts/setup-local.sh
./scripts/start-local.sh
```

Телефон и ноутбук должны находиться в одной локальной сети. Скрипт запускает FastAPI, локальную SQLite-базу и Expo Metro, а также автоматически записывает текущий IP ноутбука в `mobile/.env.local`.

Подробная архитектура, состояние функций и инструкции по обновлению приложения описаны в [PROJECT_GUIDE.md](./PROJECT_GUIDE.md). Контекст продукта находится в [PROJECT_CONTEXT.md](./PROJECT_CONTEXT.md).

Конкурсная стратегия, выбранный трек, метрики и план до дедлайна находятся в [HACKATHON_STRATEGY.md](./HACKATHON_STRATEGY.md).

Полный каталог ресурсов из технического задания, исследовательских материалов и статусов интеграции находится в [DATA_SOURCES.md](./DATA_SOURCES.md).

# 🌾 Tanap AI (Танап AI)

> **Интеллектуальная цифровая агроплатформа мониторинга полей, спутниковой аналитики Sentinel-2, полевого прогнозирования урожайности и AI-агрономических консультаций с криптографически верифицируемыми агропаспортами.**
>
> Проект разработан для AI-хакатона **Aqmola Hub** (Акмолинская область).
>
> **Tanap AI реализует задачи всех трёх конкурсных треков. Основной акцент и конкурсная подача — Трек 3: компьютерное зрение.**

---

## 🎯 Охват конкурсных треков

| Трек | Что реализовано в Tanap AI | Роль в проекте |
| :--- | :--- | :--- |
| **Трек 1 — GIS и дистанционное зондирование** | Sentinel-2 L2A, NDVI/NDMI, автоконтур поля, сетка зон риска, GeoJSON/CSV/PDF | Геопространственная основа и контекст поля |
| **Трек 2 — урожайность и агрометеориски** | Полевой ML-прогноз с 80% интервалом, Open-Meteo, NASA POWER/ERA5, окна сева и уборки | Прогнозный и управленческий контур |
| **Трек 3 — компьютерное зрение** | 3.1 — фитосанитарная гипотеза по фото; 3.2 — подсчёт всходов по фото/видео; 3.3 — визуальная оценка зерна; 3.4 — подсчёт поголовья | **Главный конкурсный акцент** |

Три трека объединены в один полевой workflow: спутник находит неоднородность, погода и модель помогают оценить риск, а компьютерное зрение помогает агроному зафиксировать и проверить обстановку на месте.

## 📋 Ключевые возможности системы

### 1. 🛰️ Спутниковая аналитика Copernicus Sentinel-2 L2A (10м)
- **Живые ряды вегетации**: Интеграция с Copernicus Data Space Ecosystem через Sentinel Hub Statistical API. Загрузка непрерывной 210-дневной сезонной истории (10-дневные периоды) с индексами **NDVI** (биомасса) и **NDMI** (влагообеспеченность).
- **Честная маска облачности**: Алгоритм SCL-фильтрации исключает облачность (`SCL=8,9`), дымку/циррус (`SCL=10`), тени облаков (`SCL=3`) и снег/лед (`SCL=11`). Для каждого периода отображается статус (`0% · Ясно над полем`, `Тени/дымка`, `Рассеянная облачность`, `Облачно`) с пояснением выборки наименее облачного пикселя (`leastCC`).
- **Мультипериодные зоны риска**: Сетка под-участков поля с динамическим выбором периода:
  - 🌾 **Пик вегетации** (максимальная зеленая биомасса летом для выявления дефицита питания и очагов сорняков).
  - 📡 **Последний снимок** (актуальное состояние).
  - **Детекция уборки**: Автоопределение стерни/зяби при падении NDVI ниже 0.30 с выводом предупреждающего баннера.
- **Интеллектуальный автоконтур (`/api/fields/auto-boundary`)**: Спектральная сегментация пашни от 3 га вокруг точки тапа по 4 признакам (NDVI, NDMI, видимая яркость, спектральные градиенты) с трассировкой внешнего края на 4–12 вершин.

### 2. 🌦️ Агрометеорология и агрономические окна (Open-Meteo)
- 7–16 дневный модельный прогноз для GPS-центроида каждого участка.
- Расчет суммы эффективных температур (GDD, база 5°C), испаряемости (ET₀), водного баланса (осадки минус ET₀) и риска ночных заморозков.
- Оценка оптимальных окон сева и уборки с проверкой температуры/влажности почвы и скорости ветра для СЗР.

### 3. 📈 Научный прогноз урожайности (Machine Learning)
- Локальная модель Ridge Regression с leave-one-season-out конформной калибровкой (80% доверительный интервал).
- Факторы: пик NDVI, средний NDMI, сезонные осадки, GDD, водный баланс ERA5 (Copernicus Climate Data Store).
- Отсутствие выдуманных цифр: при нехватке истории сервис честно сообщает о недостаточности данных.

### 4. 🤖 AI-Агроном (Google Gemini + Multi-turn Memory)
- **Региональная адаптация**: Промпты и база знаний сфокусированы на специфике Акмолинской области (чернозёмы, каштановые почвы, сорта НПЦЗХ им. Бараева: *Астана, Шортандинская, Акмола*, сорняки, болезни и реестр пестицидов РК).
- **Диалоговая память рассуждений**: Память до 30 сообщений (`build_gemini_contents`) с поддержкой уточняющих вопросов в контексте конкретного поля.
- **Скрытый агроконтекст (Under-the-hood Context)**: Координаты, погода, культура и история передаются скрытно в системные инструкции модели, сохраняя баблы чата лаконичными.
- **Голосовой полевой осмотр**: Запись голосовых сообщений агронома в Telegram-боте и веб-интерфейсе с автоматической транскрибацией и структурированием в официальный акт осмотра.
- **Компьютерное зрение**: Анализ фото растений (болезни, вредители, густота стояния всходов, качество зерна) с явным указанием, что результат является визуальной гипотезой, требующей полевой проверки.

### 5. 🛡️ Криптографически верифицируемый Агропаспорт (PDF)
- Генератор официального паспорта поля (Pillow + ReportLab) с Hi-DPI векторной картосхемой и координатной сеткой WGS-84.
- **Двухуровневый хэш SHA-256**:
  - `payload_sha256` — неизменяемый хэш канонических агрономических данных.
  - `file_sha256` — криптографический отпечаток PDF-файла.
- **Живой QR-код** на листе отчета ведет на публичный портал проверки подлинности `/verify/{report_id}` со встроенным клиентским drag-and-drop валидатором на Web Crypto API.

## 🚀 Быстрый запуск (Рекомендуемый способ)

В корне репозитория подготовлены скрипты, которые настраивают всё автоматически.

### Шаг 1. Установка всех зависимостей
```bash
./scripts/setup-local.sh
```
*Что делает скрипт:*
1. Создает виртуальное окружение Python в `backend/.venv`.
2. Устанавливает все Python-библиотеки (FastAPI, Copernicus, Shapely, Pillow, ReportLab, Argon2).
3. Создает файл `backend/.env` из шаблона `.env.example`.
4. Устанавливает зависимости фронтенда через `npm install` в каталоге `mobile/`.
5. Создает файл конфигурации `mobile/.env.local`.

### Шаг 2. Запуск проекта
```bash
./scripts/start-local.sh
```
*Что делает скрипт:*
1. Автоматически определяет ваш IP-адрес в локальной сети.
2. Прописывает `EXPO_PUBLIC_API_URL=http://<ВАШ_IP>:8000` для бесшовной связи клиента и сервера.
3. Запускает FastAPI бэкенд на `http://0.0.0.0:8000` с автоперезагрузкой (hot-reload).
4. Запускает сервер Expo Metro.

**Как открыть приложение:**
- Нажмите клавишу **`w`** в терминале — приложение мгновенно откроется в вашем веб-браузере!
- Для запуска на телефоне: отсканируйте появившийся QR-код через камеру (iOS) или приложение Expo Go (Android), находясь в одной Wi-Fi сети с компьютером.
- Документация API доступна по адресу: [http://localhost:8000/docs](http://localhost:8000/docs).

## 💻 Пошаговый ручной запуск (Manual Step-by-Step)

Если вы предпочитаете запускать компоненты вручную в отдельных вкладках терминала:

### 1. Запуск бэкенда (FastAPI)

```bash
# Перейдите в каталог бэкенда
cd backend

# Создайте и активируйте виртуальное окружение
python3 -m venv .venv
source .venv/bin/activate  # Для Linux/macOS
# Для Windows: .venv\Scripts\activate

# Установите зависимости
pip install --upgrade pip
pip install -r requirements.txt

# Создайте конфигурационный файл
cp .env.example .env

# Запустите сервер разработки
uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

Бэкенд готов:
- Swagger UI: [http://localhost:8000/docs](http://localhost:8000/docs)
- OpenAPI JSON: [http://localhost:8000/openapi.json](http://localhost:8000/openapi.json)

### 2. Запуск фронтенда (Web / Mobile)

В новой вкладке терминала:

```bash
# Перейдите в каталог мобильного приложения
cd mobile

# Установите зависимости
npm install

# Укажите адрес локального бэкенда
echo "EXPO_PUBLIC_API_URL=http://localhost:8000" > .env.local

# Запуск в режиме Web
npm run web

# Или запуск универсального Metro (Web, iOS, Android):
npx expo start
```

### 3. Запуск Telegram-бота (Опционально)

Бот работает независимо в режиме async long-polling:

```bash
cd backend
source .venv/bin/activate
# Убедитесь, что в backend/.env указан TELEGRAM_BOT_TOKEN
python -m app.telegram_bot
```

## ⚙️ Настройка переменных окружения (`.env`)

Файл конфигурации бэкенда находится в `backend/.env`.

| Переменная | Обязательна? | Описание и где получить |
| :--- | :---: | :--- |
| `JWT_SECRET` | Нет | Секретный ключ для подписи токенов (по умолчанию используется dev-ключ) |
| `COPERNICUS_CLIENT_ID` | Опционально | OAuth Client ID из [Copernicus Data Space](https://dataspace.copernicus.eu/) |
| `COPERNICUS_CLIENT_SECRET` | Опционально | OAuth Secret из Copernicus Data Space |
| `GEMINI_API_KEY` | Опционально | API-ключ Google Gemini из [Google AI Studio](https://aistudio.google.com/) |
| `GEMINI_API_KEYS` | Опционально | Пул ключей через запятую (для устойчивости к квотам) |
| `TELEGRAM_BOT_TOKEN` | Опционально | Токен бота от [@BotFather](https://t.me/BotFather) |
| `TELEGRAM_BOT_USERNAME` | Опционально | Юзернейм бота (по умолчанию `tanapai_aqmola_bot`) |
| `MINI_APP_URL` | Опционально | Публичный HTTPS-адрес веб-приложения для кнопки Меню в Telegram |
| `BREVO_API_KEY` | Опционально | Ключ Brevo для отправки email (до 300 писем/день бесплатно) |

> 💡 **Демо-режим без внешних ключей**:
> Даже если ключи Copernicus или Gemini не заданы, приложение **полностью работоспособно**:
> - При отсутствии ключа почты код подтверждения email возвращается прямо в ответе API (`devCode`), позволяя легко тестировать регистрацию.
> - Погодные данные Open-Meteo работают свободно без ключей.
> - Если спутниковые данные недоступны, система честно возвращает статус `pending` без фальсификации показателей.

## ⚖️ Соответствие принципам AgTech и честности данных

В соответствии с правилами разработки проекта Tanap AI:
1. **Никаких синтетических заглушек**: Пропущенные или затененные спутниковые пиксели возвращаются как `null`, а не заменяются нулями или усреднением «с потолка».
2. **Честная интерпретация**: Оценки нейросетей по фото обозначаются как *«визуальная гипотеза»* — система прямо указывает пользователю о необходимости полевой или лабораторной верификации.
3. **Криптографическая подлинность**: В паспортах полей полностью исключены псевдогосударственные гербы и фальшивые печати; вместо них внедрен математический стандарт проверки целостности на базе хэшей SHA-256 и открытого реестра.
